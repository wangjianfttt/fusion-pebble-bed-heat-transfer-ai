# P418球床换热研究的完整计算顺序

这份说明只回答三个问题：现在算到哪里、后面按什么顺序算、每一步得到什么。物理参数、入口条件和颗粒发热率都继续使用已经登记的文献值，不在这里增加新数值。

## 当前进度

- 60组稳态三维流动--换热工况：`40/60`，剩余20组；
- 固定流场近似下的物理热阶跃：`0/12`；
- 全流热耦合的物理热阶跃：`0/12`；
- 高雷诺数组合测试：固定流场`0/6`，全耦合`0/6`；
- PINN、图--Transformer和扩散模型的程序连接已经用小型数据跑通，但正式精度必须等待上述OpenFOAM数据。

随时可以运行下面的命令查看文件系统中的实时数量。该命令只读文件，不会启动求解器或神经网络训练。

```bash
python3 code/plan_hccb_p418_end_to_end_research.py
```

正式总入口默认也只打印同一份计划：

```bash
bash code/run_hccb_p418_formal_calculations.sh
```

在已经安排好的云端环境中显式设置`EXECUTE=1`后，同一总入口会按本页顺序依次调用：固定流场后处理、全耦合时间步检查、12条全耦合曲线、全耦合模型、seed202/seed303、两组高速端测试、大区域对照和论文刷新。每一步已有完成记录时直接复用，没有完成记录时才执行；最终记录保存全耦合模型和高速端比较文件的校验值。工作站暂停标记存在时，新增求解仍会停止。

## 后续顺序

第一步完成seed101的60组稳态三维场。OpenFOAM 13、MPI、运行时间、内存和云端/工作站结果一致性已经通过代表工况检查；当前继续补齐剩余20组。稳态工况完成后，才能统一生成最终温度、速度、压力、压降、壁面换热和颗粒热点数据。

第二步计算固定流场近似下的12条物理热阶跃，并比较响应面、PINN、区域图模型、Transolver、DMDc、POD、图--Transformer和扩散温度修正。这里的扩散模型只修正图--Transformer的温度残差，不改变速度、压力、质量流和边界条件。

第三步先计算一条全流热耦合代表阶跃的三档时间步，再计算12条全耦合曲线。固定流场与全耦合曲线按相同源工况、目标工况和记录时刻逐条比较，直接得到固定速度和压力场近似对压降、出口温度、颗粒最高温度、冷却壁换热和能量变化的影响。

这12对曲线完成后会自动生成：

```text
results/hccb_p418_fully_coupled_steps_12/fixed_vs_fully_coupled/
manuscript/generated_fixed_vs_fully_coupled_steps.tex
manuscript/generated_fixed_vs_fully_coupled_text.tex
```

比较保留8个物理量：压降、出口温度、颗粒最高温度、流体平均温度、颗粒平均温度、冷却壁热量、质量余量和出口焓流。每个量分别给出12条曲线的中位RMSE、最大有量纲差异和相对全耦合响应幅度的最大差异。不同单位不相加，也不人为规定一个统一通过百分比。

第四步用全耦合12条曲线训练完整状态图--Transformer。训练曲线用于更新网络，检查曲线用于选择损失组合和训练轮数，独立测试曲线只在模型确定后读取一次。这样得到的结果才能回答模型对未参加训练的流动--换热过程是否有效。

全耦合模型的明确入口是：

```bash
EXECUTE=1 DEVICE=cuda bash code/run_hccb_p418_fully_coupled_model_stage.sh
```

它先比较固定等权和三组来自公开论文设置的ReLoBRaLo组合，只读取训练曲线和检查曲线；选定组合后再读取独立测试曲线。默认不加`EXECUTE=1`时只打印完整命令。

第五步计算seed202和seed303两套独立颗粒装填。seed202用于确定最终网络结构；结构固定后，seed303只做独立预测，不能再反过来修改模型。

第六步在所有模型设置已经固定后，计算6组高速端工况组合。固定流场和全耦合各有6条，全部工况值来自P418原始`5×4×3`矩阵。这些曲线不参加归一化、训练、损失组合选择、POD基底或扩散训练，只用于检验高速端的组合迁移能力。

两组高速端计算完成后，会自动调用冻结模型预测程序：

```bash
MODE=fixed EXECUTE=1 bash code/run_hccb_p418_high_re_independent_steps.sh
MODE=fully_coupled EXECUTE=1 bash code/run_hccb_p418_high_re_independent_steps.sh
```

固定流场分支报告流体和颗粒温度误差、最高颗粒温度时程、热点区域位置和能量方程差异；全耦合分支另外报告速度、压力、内部面质量流和边界面质量流误差。全耦合结果还逐条计算连续性、动量、流体能量、颗粒能量、流固界面换热以及内部面和边界面质量流关系。方程尺度只读取主模型训练曲线已经保存的数值，高速端曲线不参与确定尺度。结果同时保存模型预测与OpenFOAM参考之间的方程差，以及二者各自的方程余量，便于区分“场变量接近”与“物理关系也接近”。六条高速端曲线只读取主训练集得到的均值、标准差、方程尺度和网络权重，不会重新计算归一化，也不会重新选择模型。

固定流场和全耦合两组冻结预测都完成后，程序自动生成一份联合结果，位置为：

```text
results/hccb_p418_high_re_independent_model_comparison/
```

其中包含同一6条曲线的逐曲线比较、总指标比较、八类方程比较、中文结果说明和可插入论文的LaTeX表格。温度、热点、速度、压力、质量流和方程误差分别保留各自单位，不合成单一总分。两类结果未同时完成时，程序只提示缺少数据，不生成数值表。

联合结果完成后，LaTeX表格同时写入：

```text
manuscript/generated_high_re_comparison.tex
```

论文正文把它放在固定流场热阶跃之后，单独讨论高速下固定流场近似与全耦合预测的差别。最终讨论和结论也直接读取联合结果文件；只要六条曲线、两套冻结模型或联合表缺一项，最终论文刷新就会停止，不会使用预计值或手工填写值。

最后由程序重新生成论文图、表和PDF。正文重点报告四个问题：三维热点能否被恢复；主12条曲线和高速端曲线中固定流场近似分别造成多大误差；图--Transformer和扩散修正相对传统模型提高多少；模型在新颗粒排列和高速端工况组合上是否仍然可靠。
