# P418 球床换热参数与方程对应关系

## 1. 为什么需要这张表

这张表回答三个直接问题：

1. OpenFOAM 和神经网络方程里每个物理量来自哪篇文献；
2. 同一个物理量在 OpenFOAM 字典和 Python 方程中是否一致；
3. 哪些数值是物理参数，哪些只是时间步、训练轮数等数值计算设置。

逐行数据见 `hccb_p418_equation_input_map.csv`。

## 2. 正式求解方程

流体质量守恒为

```text
div(rho_f u) = 0
```

流体稳态能量方程为

```text
div(rho_f u h_f) - div(k_f grad(T_f)) = 0
```

颗粒稳态能量方程为

```text
-div(k_s grad(T_s)) - q''' = 0
```

流固界面满足温度连续和热流守恒：

```text
T_f = T_s
q_f + q_s = 0
```

热阶跃计算使用OpenFOAM-13的守恒焓形式。流体储热和压力功项为：

```text
d(rho_f h_f)/dt + d(rho_f K)/dt - dp/dt
K = |U|^2/2
```

流体方程还保留动能随质量流的输运项`div(phi K)`，其中`phi`直接读取目标工况收敛后的OpenFOAM面质量流。固体储热为：

```text
rho_s d(e_s)/dt
```

`e_s(T)`由P428--P431纯Li4SiO4量热关系积分得到，其温度导数就是P429比热。该写法在温度相关比热下比直接写`rho_s c_p dT/dt`更接近OpenFOAM内部能方程。

区域神经网络没有另写一套经验传热方程。它在保留下来的有限体积子面、流固界面和边界条件上计算质量与能量算子。由于多个原网格单元被平均为一个区域，区域化OpenFOAM温度场的绝对残差不等于原网格求解残差；正式训练比较预测场与同一区域化OpenFOAM场的能量算子差，原始OpenFOAM收支另外独立报告。

## 3. 神经网络实际读取的物理输入

稳态模型读取：

- 入口速度 `u_in`；
- 入口温度 `T_in`；
- 颗粒体积发热率 `q'''`；
- 出口绝对压力 `p_out`；
- 冷却壁温度 `T_wall`；
- 区域坐标、体积、流体/颗粒类型和有限体积连接关系。

热阶跃模型同时读取阶跃前后的入口速度、入口温度和发热率。出口压力和冷却壁温度在 12 条正式阶跃中保持文献值。目标稳态速度和压力场保持不变，只求解流体和颗粒温度随时间的变化。

## 4. 物性怎样进入方程

- 氦气密度、黏度和导热系数随局部温度变化；密度和导热系数还使用绝对压力；
- 氦气比热采用文献给出的 `5200 J/(kg K)`；
- Li4SiO4 导热系数采用 `1.42 W/(m K)`；
- Li4SiO4 密度采用 `1526.4 kg/m3`；
- 正式热阶跃采用 Kleykamp 高温量热关系计算温度相关比热；
- 938 K 和 996 K 附近的二级相变峰没有被平滑比热关系解析，因此接近该温区的结果不能解释成相变精细预测。

## 5. 已完成的实际算例核对

`code/verify_hccb_p418_actual_case_inputs.py` 已逐个读取 60 个算例的 OpenFOAM 字典。结果保存在：

```text
results/hccb_p418_60_actual_case_input_check/summary.json
```

核对结果为：

- 60 个工况全部来自 P418 的 `5 x 4 x 3` 工况矩阵；
- 入口速度、入口温度、体积热源、压力、壁温和材料参数均与文献登记表一致；
- 60 个工况共用同一固定三维网格；
- 没有新增拟合的球床物理参数；
- 时间终点、写出间隔、并行核数和网络结构均单列为数值计算设置。

## 6. 当前物理范围

当前结果描述一个固定 Li4SiO4 堆积上的局部三维孔隙尺度流固换热。它可以研究工况变化、局部绕流、热点和壁面热流，但还不能代表不同堆积、不同颗粒破碎状态或完整包层模块。跨堆积泛化需要增加独立装填数据，模块级扩展需要真实模块几何和冷却流路。
