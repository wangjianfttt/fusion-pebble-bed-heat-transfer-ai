# P418数据与代码许可建议

## 建议组合

- 程序、脚本和小型复现工具：`MIT License`
- 处理后的数值数据、绘图表格和模型预测结果：`CC BY 4.0`

## 原因

MIT许可证允许其他研究者使用、修改和再发布程序，同时要求保留版权和许可说明，适合本项目的Python、Shell和OpenFOAM扩展代码。

CC BY 4.0允许其他研究者复用处理后的数据和图表，但必须注明来源，适合作为Zenodo数据集发布。论文、第三方文献PDF、出版社图件以及不属于作者的外部代码不纳入本项目许可证。

## 发布时的文件安排

1. 项目代码根目录放置MIT许可证全文，并在README中注明代码许可。
2. Zenodo数据记录选择`CC BY 4.0`，数据包README中注明数据许可。
3. `CITATION.cff`和Zenodo元数据使用同一题目、作者顺序和版本号。
4. 原始OpenFOAM大场保留在机构/NAS存档中；公开包提供处理后数据、必要几何、校验值和恢复说明。
5. 已发表论文PDF、外部实验原图和第三方代码只保留DOI或来源链接，不放入公开压缩包。
